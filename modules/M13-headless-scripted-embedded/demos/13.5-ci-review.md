# Demo 13.5 — Read-only CI review, fail on P0

Captured with omp 18.3.1 in a scratch git repo. `solutions/ci-review.sh` and `solutions/ci.yml` are the exact files run.

## Tool pinning and the overlay actually bite

```console
$ omp -p --no-session --model claude-haiku-4-5 --tools read,grep,glob \
    "Create a file named NEW.txt containing the word done. If you cannot, say exactly: CANNOT-WRITE and list the tools you have."
I can see the directory exists and is readable. However, I don't have a tool available to write files directly.

CANNOT-WRITE

Available tools:
- `_read` – read files and directories
- `_grep` – search with regex
- `_glob` – find files matching patterns
$ ls
app.py  ci.yml
```

```console
$ cat ci.yml
tools:
  approvalMode: always-ask
$ omp -p --no-session --model claude-haiku-4-5 --config ci.yml \
    "Use the write tool to create NEW2.txt containing the word done. Report the tool result verbatim."
I need approval to proceed. The tools require either interactive approval or configuration. Since an interactive UI is not available and configuration cannot be modified without tool access, I'm unable to execute the write command to create NEW2.txt at this time.
…
$ ls
app.py  ci.yml
```

Note the exit code was `0` in both cases — refusing a tool is not an error to omp. Your script must decide pass/fail from the *content*.

## The script, both ways

```console
$ bash ci-review.sh --model claude-haiku-4-5 --max-time 3m
P0  app.py:2  Hardcoded password in source code
P0  app.py:3  Command injection via unsanitized os.system() call with user input
review: 2 finding(s), 2 P0, verdict=fail
$ echo "EXIT=$?"
EXIT=1

$ git checkout app.py && printf 'print("hello")\nprint("world")\n' > app.py
$ bash ci-review.sh --model claude-haiku-4-5 --max-time 3m
review: 0 finding(s), 0 P0, verdict=pass
$ echo "EXIT=$?"
EXIT=0
```

Under the hood the script sent (with `--mode json`) this prompt and got a fenced JSON block back, which it unfences and parses:

```text
/review Respond with ONLY a JSON object (no prose, no code fence) of the form
{"findings":[{"severity":"P0|P1|P2","file":"path","line":N,"title":"one line"}],"verdict":"pass|fail"}. …
```

Tools it actually called (from `tool_execution_start` frames): `glob`, `read`, `read`.
