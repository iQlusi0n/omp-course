# Demo 13.1 — Print mode (`-p`), text and JSON

Captured on the build machine with omp 18.3.1 and `anthropic/claude-haiku-4-5`. `--no-extensions --no-skills --no-rules --thinking off` were added only to keep the transcript short; they are not required.

## Text mode, prompt on stdin, stdout is *only* the answer

```console
$ echo "Reply with exactly the word: pong" | omp -p --no-session --no-tools --model claude-haiku-4-5
Working...
pong
$ echo "EXIT=$?"
EXIT=0

$ echo "Reply with exactly the word: pong" | omp -p --no-session --no-tools --model claude-haiku-4-5 2>/dev/null | od -c
0000000   p   o   n   g  \n
```

`Working...` is written to **stderr**. stdout carries the model text and nothing else.

## `--print-thoughts` adds the thinking block to the text output

```console
$ omp -p --print-thoughts --no-session --no-tools --thinking low --model claude-haiku-4-5 "Reply with exactly the word: hi"
Working...
The user is asking me to reply with exactly the word "hi". This is a straightforward instruction. I should comply with this direct request.
hi
```

## Exit codes

```console
$ omp -p --no-session --no-tools --model does-not-exist-zzz "hi"

Set an API key environment variable:
  ANTHROPIC_API_KEY, OPENAI_API_KEY, GEMINI_API_KEY, etc.

Or create /home/user/.omp/agent/models.yml
$ echo "EXIT=$?"
EXIT=1

$ omp -p --no-session --no-tools --model claude-haiku-4-5 --max-time 1 "Write a 500 word essay about rivers" >out.txt

Deadline exceeded
$ echo "EXIT=$?"; wc -c out.txt
EXIT=1
0 out.txt
```

## A run that calls a tool (event types only)

```text
session → agent_start → turn_start
message_start user → message_end user
message_start assistant [toolCall]
  message_update toolcall_start / toolcall_delta… / toolcall_end
message_end assistant (stopReason: "toolUse")
tool_execution_start  {toolCallId, toolName:"read", args:{path:"app.py"}, intent:"…"}
tool_execution_end    {toolCallId, toolName:"read", result, isError:false}
message_start toolResult → message_end toolResult
turn_end
turn_start
message_start assistant [text] → text_start / text_delta… / text_end → message_end assistant (stopReason: "stop")
turn_end → agent_end
```

## Extract only the final answer with `jq`

```console
$ omp -p --mode json --no-session --tools read,grep,glob "Which python files are in this directory? One line." 2>/dev/null \
  | jq -r 'select(.type=="message_end" and .message.role=="assistant") | .message.content[] | select(.type=="text") | .text'
`app.py` is the only Python file in this directory.
```

(With multi-turn tool use there are several assistant `message_end` frames; the *last* one is the answer — see `exercises.md` W1 for the `jq -s` form.)
