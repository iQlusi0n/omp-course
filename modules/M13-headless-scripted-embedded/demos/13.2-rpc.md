Captured with omp 18.3.1. Frames are shown as omp emitted them (long ones trimmed with `…`).

stdin closed after one line → omp drained, disposed the session, exited `0` (rpc.md "Startup").

## `solutions/rpc_client.py` — prompt, stream, let it finish

```console
$ python3 solutions/rpc_client.py --model claude-haiku-4-5 --tools read,grep,glob "Reply with exactly the word: hello"
[ready] protocolVersion=1 maxFrameBytes=1048576
[state] model=anthropic/claude-haiku-4-5 isSettled=True
[ack] prompt accepted agentInvoked=None
hello
[prompt_result] status=completed sessionSettled=True
[exit] omp exited 0
$ echo "EXIT=$?"
EXIT=0
```

Bracketed lines are the client's stderr; `hello` is the concatenated `text_delta` stream on stdout.

## Same client, `--abort-after 1.5`

```console
$ python3 solutions/rpc_client.py --model claude-haiku-4-5 --tools read,grep,glob --abort-after 1.5 \
    "Write a 1500 word essay about rivers, streaming it as you go."
[ready] protocolVersion=1 maxFrameBytes=1048576
[state] model=anthropic/claude-haiku-4-5 isSettled=True
[ack] prompt accepted agentInvoked=None

[abort] success=True

[prompt_result] status=aborted sessionSettled=True
[exit] omp exited 0
$ echo "EXIT=$?"
EXIT=0
```

Wire sequence behind that run:

```json
→ {"id":"req_1","type":"negotiate_protocol","protocolVersion":2}
← {"id":"req_1","type":"response","command":"negotiate_protocol","success":true,…}
→ {"id":"req_2","type":"get_state"}
← {"id":"req_2","type":"response","command":"get_state","success":true,"data":{…}}
→ {"id":"req_3","type":"prompt","message":"Write a 1500 word essay…"}
← {"id":"req_3","type":"response","command":"prompt","success":true}
← {"type":"agent_start"} … {"type":"message_update","assistantMessageEvent":{"type":"text_delta",…}} …
→ {"id":"req_4","type":"abort"}
← {"id":"req_4","type":"response","command":"abort","success":true}
← {"type":"agent_end",…}
← {"type":"prompt_result","id":"req_3","agentInvoked":true,"status":"aborted","sessionSettled":true}
← {"type":"session_settled"}
```
