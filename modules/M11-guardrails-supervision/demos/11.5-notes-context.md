# Demo 11.5 — Notes-backed context: `context_notes` → `new_context` → `history://current/full` (≤ 60 s)

Reconstructed TUI transcript (`omp/18.3.1`). Verified strings: tool labels *Context Notes* /
*New Context*, results `Context notes saved.`, `No context notes are stored for this session
branch.`, `New context window requested.`, the byte-limit error, the compaction divider
`── 📷 compacted · ctrl+o ──`, and `Usage: /extended-context [on|off|status]`. Notebook text is
illustrative. No recording exists on the build machine.

What crossed the boundary and what did not:

| kept in the new window | recoverable only via `history://current/full` |
|---|---|
| latest `context_notes` revision (331 bytes) | the full text of `docs/ISSUES.md` read earlier |
| complete recent tool-call/result units | older assistant reasoning and tool results |
| system prompt, `AGENTS.md` family | the first notebook revision (118 bytes) |

No summarisation model ran — that is the point of the mode.

Recovering raw detail from the earlier window:

```text
> read history://current/full:1-40
  #1  user      Before you start: save a context note …
  #2  assistant [tool_call context_notes {text: "# Goal\nimplement issue #8 fix …"}]
  #3  tool      Context notes saved.
  #4  assistant [tool_call read {path: "docs/ISSUES.md"}]
  #5  tool      # Issues … #8 …
  …
  ── window boundary ──
  …

> grep "catch-all" history://current/full
  #5: … #8 — it is tempting to wrap the handler in a catch-all and return 400 for everything …
```

Error you will hit if the notebook grows past the limit:

```text
  ▸ Context Notes                                                        ✗
      Context notes are 17204 bytes; the limit is 16384 UTF-8 bytes. Shorten the notebook and use history://current/full to recover raw detail.
```

Extended context toggle (separate feature, same lesson):

```text
> /extended-context status
  Extended context is …
> /extended-context on
  Extended context enabled.
> /extended-context status
  Extended context is …
> /extended-context maybe
  Usage: /extended-context [on|off|status]
```

(`Extended context enabled.` / `Extended context disabled.` and the `Usage:` line are verbatim
binary strings; the `status` line starts with `Extended context is` and its value wording is not
documented — treat the tail as illustrative.)
