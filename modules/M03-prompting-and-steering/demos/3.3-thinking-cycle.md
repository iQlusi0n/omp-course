# Demo 3.3 — Thinking level: cycle, show, `ultrathink`

Representative transcript (not a recording). The status-line model segment is drawn as `[model ⟨icon⟩]`; with `statusLine.compactThinkingLevel: false` it reads `[model · high]` instead. Border colors are theme tokens `thinkingOff` … `thinkingMax` and cannot be shown in text.

## Cycle with `Shift+Tab`

```text
status line:  [claude-… ⟨high⟩]  ctx 3%  omp-course-lab  main     ← starts at defaultThinkingLevel
              ↓ Shift+Tab
status line:  [claude-… ⟨▲⟩]      icon changes; border color changes with it
              ↓ Shift+Tab
status line:  [claude-… ⟨▲▲⟩]     keep pressing until the level you want shows
```

The order and the set of levels you pass through depend on what the current model exposes; read the icon (or the ` · <level>` suffix with `statusLine.compactThinkingLevel: false`) rather than counting presses. `/hotkeys` lists the live chord if your terminal remaps it. `defaultThinkingLevel` (`high`) is the starting level for a session; `Shift+Tab` changes the current session's level, which is persisted with the session.

## Show/hide blocks with `Ctrl+T`

```text
› Explain in five lines how cli/__main__.py parses --month.            (level: low)

  ▸ thinking (hidden)                       ← Ctrl+T →   ▾ thinking
                                                          Need to look at the argparse setup; the
                                                          --month option probably uses a type= callable…
● read cli/__main__.py
1. `--month` is declared on the `orders` subparser …
```

`Ctrl+T`, `--hide-thinking`, and `hideThinkingBlock` only change what you see; `--thinking off` changes what the model does.

## Same question at `high`

```text
› Explain in five lines how cli/__main__.py parses --month.            (level: high)

  ▾ thinking
    The user wants a five-line explanation. First read cli/__main__.py to see the argparse
    definition; check whether --month is validated (YYYY-MM) and where the value flows
    (commands.py?). Keep to five lines. …
● read cli/__main__.py
● grep month cli/
1. …
```

Longer block, same five lines. For a question this size the level is a cost dial.

## An `ultrathink` turn

While typing, the word renders with an animated gradient:

```text
› ~ultrathink~ about whether the csv writer in cli/commands.py handles a status value containing a comma;
  list every branch you checked
```

Sent on a fixed level (`high`): the level does **not** change; a hidden user-attributed notice ("reason carefully, multi-step") is added for this turn only. Sent on `auto`: the turn additionally runs at the highest effort the model supports (up to `max`; `providers.autoThinkingMaxEffort` caps plain `auto` at `xhigh`).

Things that do **not** trigger (no gradient): `Ultrathink`, `ultrathink()`, `ultrathink.ts`, `` `ultrathink` ``, anything inside a fenced block.

```text
› !omp config get magicKeywords.ultrathink
   true
```
