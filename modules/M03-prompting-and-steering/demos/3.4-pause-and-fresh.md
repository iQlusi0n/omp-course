# Demo 3.4c — `/pause` and `/fresh`

Representative transcript (not a recording).

## `/pause`: park everything without aborting

```text
› Read every file under api/ and summarize the request flow in notes/api-flow.md.

● read api/__init__.py
● read api/…            (in flight)
› /pause

  ┌ Paused ─────────────────────────────────────────────────────────────┐
  │ Main agent, subagents, and advisor park at their next safe boundary. │
  │ In-flight calls finish; nothing new starts.                          │
  │ Esc / Enter / Space / Ctrl+C to resume                               │
  └──────────────────────────────────────────────────────────────────────┘
                     Space
● read api/…            (continues exactly where it parked)
● write notes/api-flow.md
```

- TUI only. The gate is process-global: in-process subagents (Module 10) and the advisor (Module 11) park too.
- `Ctrl+C` on the pause screen **resumes**; it does not abort. To abort, resume first and press `Esc`.

## `/fresh`: new provider stream state, same conversation

Symptom: a turn hangs or errors repeatedly the same way (stale prompt cache, drifted server-side conversation id, mid-turn glitch). `Alt+R` retries the last failed turn; when retrying reproduces the wedge, reset the provider side:

```text
  Esc                     ← /fresh is rejected while streaming; abort first
› /fresh
  Fresh provider session: pruned 2 cached provider-session entries.   (count varies)

› What was my very first message in this session?
Your first message asked me to implement issue #3 …    ← the local transcript was re-sent in full
```

What changed: provider-session/prompt-cache handles closed, new provider session id, next turn re-sends the whole local transcript (expect a cache miss on that turn). What did not change: transcript, session file, session id, anything you can see.

Not to be confused with (Module 5): `/clear` clears the live conversation, `/new` starts a new session, `/delete` deletes this one and starts new. Only `/fresh` keeps the conversation.
