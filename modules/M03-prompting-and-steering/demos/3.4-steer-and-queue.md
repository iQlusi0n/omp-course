# Demo 3.4a — Steer, follow-up, dequeue, `Esc`

Representative transcript (not a recording). `›` your message, `●` tool card, `⇢` a queued message shown by the TUI, `⋯` elided.

## Steer: type + `Enter` while the turn runs

```text
› For every function in cli/ and api/, read the file and write a one-line description
  into notes/functions.md, one section per file.

● read cli/__main__.py
● read cli/commands.py
● read api/__init__.py
  (you type)  Only cli/. Skip api/ entirely.   ⏎
⇢ steer queued: Only cli/. Skip api/ entirely.
● read api/server…  ✗ aborted                 ← interruptMode: immediate — remaining calls in the batch are cut
› Only cli/. Skip api/ entirely.               ← delivered at the tool boundary
Understood — restricting to cli/.
● write notes/functions.md
Done: notes/functions.md has sections for cli/__main__.py and cli/commands.py.
```

- `steeringMode: one-at-a-time` (default): one queued steer is delivered per turn; `all` drains them together.
- `interruptMode: wait` would hold the same message until the turn ends.
- If the model finishes before any tool boundary, your text is sent as an ordinary next prompt — no harm done.

## Follow-up: `Ctrl+Q` (or `Ctrl+Enter`)

```text
› Now do the same for api/ into notes/functions-api.md.

● read api/__init__.py
  (you type)  When finished, run git status --short and show it.   Ctrl+Q
⇢ follow-up queued (1)
● read api/…
● write notes/functions-api.md
Done.
                                            ← turn ends; the queue delivers
› When finished, run git status --short and show it.
● bash git status --short
    ?? notes/functions-api.md
    ?? notes/functions.md
```

The running turn was not interrupted. `followUpMode` mirrors `steeringMode`.

## Dequeue: `Alt+Up` / `Shift+Up`

```text
⇢ follow-up queued (1): When finished, run git status --short and show it.
  Alt+Up
  ┌ composer ─────────────────────────────────────────────┐
  │ When finished, run git status --short and show it.    │   ← back in the editor, unsent
  └───────────────────────────────────────────────────────┘
  Ctrl+C  → editor cleared      Up → recalled (composer.recallClearedDrafts: true)
```

## `Esc` once vs twice

```text
● bash python3 -m unittest discover -s tests -v
    test_orders_table … ok
    ⋯                      Esc
    ✗ aborted by user                     ← turn stops; everything above stays

  (composer empty)        Esc             ← second Esc on an EMPTY editor
  ┌ Rewind ───────────────────────────────┐
  │ (transcript picker: choose a point)   │   ← doubleEscapeAction: rewind (default)
  └───────────────────────────────────────┘   Esc closes it; `omp config set doubleEscapeAction none` to disable
```
