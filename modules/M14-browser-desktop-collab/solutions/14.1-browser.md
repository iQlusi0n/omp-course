# Instructor notes — 14.1 Browser (W, G, S)

## 14.1-W reference cell (verified on omp 18.3.1, JS)

```js
const tab = await browser.open({ name: "signup", url: "http://127.0.0.1:8080/", wait_until: "load" });
const obs = await tab.observe();
const byName = (n) => obs.elements.find(e => e.name.trim() === n);
const email = `m14-${Date.now()}@example.com`;   // seeded users (ada@example.com, …) already exist → duplicate = 500
await tab.id(byName("Name").id).fill("Ada Lovelace");
await tab.id(byName("Email").id).fill(email);
await tab.id(byName("Sign up").id).click();
const banner = await tab.run(async ({ tab }, sel, expected) => {
  await tab.waitForSelector(sel, { visible: true, timeout: 5000 });
  const text = await tab.evaluate((s) => document.querySelector(s).textContent, sel);
  if (text !== expected) throw new Error(`banner was ${JSON.stringify(text)}`);
  return text;
}, { args: ["#banner", "Welcome aboard!"], timeout: 30 });
console.log("banner:", banner);
console.log("screenshot:", await tab.screenshot({ silent: true }));
await tab.close();
```

Python equivalent uses direct helpers: `fill("#name", …)`, `click("#submit")`, `waitForSelector("#banner", visible=True, timeout=5000)`, `evaluate("document.querySelector('#banner').textContent")`. Python `tab.run` takes a JS **string**; `page.$eval` works inside it.

Grading: the eval card must contain `banner: Welcome aboard!`; `notes/14-1-signup.webp` (or `.png` if their build writes PNG) must exist. A learner who asserts via `extract("text").includes("Welcome aboard!")` also passes — mention that it is weaker (matches anywhere on the page).

Common learner failures (all observed):
- `document is not defined` — put DOM access in `tab.evaluate` / `page.$eval`, not bare in `tab.run`.
- `timed out after 5ms` — `waitForSelector` timeout is ms.
- Python `tab.evaluate("() => …")` returns `{}` — pass an expression string.
- A cell that throws before `tab.close()` leaves the tab open; next `open` prints `Reused tab` and navigates — harmless, but `browser.close({ all: true })` resets cleanly.
- Duplicate-email 500 from the API (`Signup failed: internal error` in the banner; the cell throws `banner was "Signup failed: internal error"`): the seeded `data/lab.sqlite` already holds `ada@example.com` and eleven other `<first>@example.com` users, and every successful run adds one more row (lab issue #8: no 409 yet). Fix: a fresh email per run (`m14-${Date.now()}@example.com`); reseed with `git checkout -- data/lab.sqlite` or `python3 tools/seed_db.py`. Restarting the service does not help — the DB is a file, not in-memory.

## 14.1-G — agent() wrapper

Expected shape:

```js
const h = await agent(
  "Open http://127.0.0.1:8080/ in a browser tab named 'signup-bg'. Fill Name and Email (invent a fresh email), click Sign up, wait for #banner to be visible, and reply with the exact banner text and the path from tab.screenshot(). Close the tab.",
  { label: "ui-check" }
);
console.log(h.handle, h.status);
```

Grading: (1) cell returns immediately with `agent://<id>`; (2) a delivery card arrives later containing `Welcome aboard!` and a path; (3) `read agent://<id>` returns the same. If the learner `await h.wait()`ed, the cell blocks and the delivery is consumed — still a pass if the result is correct, but point out the difference (the exercise asked for a background job). If `Alt+A` shows the child stuck on `browser.open`, the most common cause is a tab-name collision with the parent's still-open `signup` tab across kinds — it is not a collision here (same headless kind), but an unclosed parent tab plus a same-named child open would *reuse* it; hence the distinct name.

Approval-mode note: subagents run yolo; the parent `agent()` call is the boundary. `tools.approval.eval: prompt` would reject in the headless child.
