# Demo 14.1 — Signup smoke test with the `browser` prelude (~60 s)

Captured on omp 18.3.1 against a stand-in copy of `web/index.html` served on `127.0.0.1:8080` (same ids, title, and banner as the lab, but **without** the lab's seeded user table). Against the real `python3 -m api`, `ada@example.com` already exists in `data/lab.sqlite` and `POST /signup` returns 500 on a duplicate (lab issue #8), so the cells below use a fresh timestamped email; the email values in the transcript were substituted accordingly. Other output lines are verbatim; the screenshot hash will differ.

## 3. Fill, submit, assert, screenshot (same cell style — observe and act together)

```
┌ eval js
│ const tab = await browser.open({ name: "signup", url: "http://127.0.0.1:8080/", wait_until: "load" });
│ const obs = await tab.observe();
│ const byName = (n) => obs.elements.find(e => e.name.trim() === n);
│ const email = `m14-${Date.now()}@example.com`;   // seeded DB already has ada@example.com
│ await tab.id(byName("Name").id).fill("Ada Lovelace");
│ await tab.id(byName("Email").id).fill(email);
│ await tab.id(byName("Sign up").id).click();
│ const banner = await tab.run(async ({ tab }, sel, expected) => {
│   await tab.waitForSelector(sel, { visible: true, timeout: 5000 });   // ms
│   const text = await tab.evaluate((s) => document.querySelector(s).textContent, sel);
│   if (text !== expected) throw new Error(`banner was ${JSON.stringify(text)}`);
│   return text;
│ }, { args: ["#banner", "Welcome aboard!"], timeout: 30 });
│ console.log("banner:", banner);
│ console.log("screenshot:", await tab.screenshot({ silent: true }));
│ console.log(await tab.ariaSnapshot());
│ await tab.close();
│
```

## 5. Two mistakes you will make (observed)

```
┌ eval py
│ banner = await tab.run("return document.querySelector('#banner').textContent;")
│ RuntimeError: document is not defined
└   → tab.run executes in the browser worker, not the page. Use page.$eval / tab.evaluate.

┌ eval py
│ await tab.waitForSelector("#banner", visible=True, timeout=5)
│ RuntimeError: tab.waitForSelector("#banner") timed out after 5ms; selector currently matches
│ 1 element(s) but the action never became possible — the element may be hidden or covered
└   → timeout is milliseconds.
```
