# Demo 14.4 — Stream, record, play, clip (~60 s)

Lines marked *(observed)* were run on the build machine (no Stencil login, no TTY). The `omp stream` success output is the example from `omp://stream.md`.

## 0. Without a Stencil login (observed)

```
$ omp stream --no-tui --title "M14 probe"
stream: a stencil.so account is required: run omp and use /login → Stencil, or set STENCIL_API_KEY
(exit 1)
```

Fix: in any omp session `/login` → **Stencil (stencil.so account)**. Scripts: `STENCIL_API_KEY=<token>`.

## 1. Stream (after login), from the lab root

```
$ omp stream --title "Refactoring the parser"
● live.omp.sh/your_username  "Refactoring the parser"
  waiting for sessions in /work/proj …
```

Console (full-screen chat): type + Enter chats as owner · `/title <text>` · `/quit` or Ctrl-C stops · Up/Down recalls.

Second terminal, **same directory**, started **after** the streamer:

```
$ omp
  … footer: ● LIVE 0        (viewer count; becomes 1 when you open the viewer page)
› read .env.example
  LAB_TOKEN=••••••           ← on the viewer page: NAME=value row with a *_TOKEN name → value masked, row sent unstyled
  DATABASE_URL=sqlite:///data/lab.sqlite   ← untouched
```

A session that was already running before `omp stream` started is not attached — restart it.

## 2. Record (no account needed)

```
› /record
  … footer: ● REC
› How many tests are in tests/?
  (normal turn)
› /record
  (prints the path) /tmp/omp-recordings/<utc-time>-<session>.ompcast
```

File head: `{"ompcast":1,"cols":…,"rows":…,"title":…,"createdAt":…}` then `[ms, frame]` lines (`reset`, `history`, `resize`, `viewport`, `patch`). Rows are already redacted at record time.

## 3. Play

```
$ omp play                     # newest recording
$ omp play <file> -s 2 -i 1    # 2× speed, pauses capped at 1 s
  Space pauses/resumes · q / Esc / Ctrl-C quits · scrollback stays after playback

$ omp play /nonexistent.ompcast          (observed, from a pipe)
error: omp play needs an interactive terminal
```

## 4. Clip (Stencil login)

```
$ omp clip -t "Signup smoke via omp browser" -d "Module 14"
live.omp.sh/c/<id>

$ omp clip /nonexistent.ompcast          (observed)
error: recording not found: /nonexistent.ompcast
```

## 5. Voice surface (observed CLI; TUI keys from omp://keybindings.md)

```
$ omp setup speech --check                                (observed, fresh machine)
Speech dependencies:
  [missing] Speech-to-Text model: parakeet-tdt-0.6b-v3 — not downloaded
  [missing] Text-to-Speech model: kokoro — model/runtime not installed

$ omp config get stt.enabled     → false      (observed)
$ omp config get live.voice      → sol        (observed)
```

- `Ctrl+L` = `app.live.toggle` — start/stop live voice mode, same as `/live`.
- `app.stt.toggle` is unbound: **hold Space** to record, release to transcribe (needs `stt.enabled: true` and the dictation model from `omp setup speech`).
