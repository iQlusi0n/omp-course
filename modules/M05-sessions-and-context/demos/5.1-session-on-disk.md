# Demo 5.1 — What a session file looks like (≤ 60 s)

Captured on omp 18.3.1. A one-turn `-p` run with a custom `--session-dir`, then a look at the file.

```text
$ omp --session-dir /tmp/m5sessions -p "Read calc.py and tell me in one sentence what the bug is. Do not edit anything."
Working...
The bug is that `add` subtracts instead of adding: line 2 returns `a - b` when it should return `a + b`.

$ ls /tmp/m5sessions/
2026-09-25T17-19-21-278Z_01a0d994-2abe-763b-a400-292c817518fe.jsonl
```

First 256 bytes are the title slot; then the header; then one entry per line (fields trimmed):

```text
{"type":"title","v":1,"title":"","updatedAt":"2026-09-25T17:19:21.278Z","pad":"          …"}
{"type":"session","version":3,"id":"01a0d994-2abe-763b-a400-292c817518fe","timestamp":"…","cwd":"/tmp/m5lab"}
model_change           id cbc335f2  parent null      model anthropic/claude-opus-5-5
thinking_level_change  id 515992bc  parent cbc335f2  thinkingLevel high
message                id 91f79eab  parent 515992bc  role user        [text]
message                id 5d6c6f1d  parent 91f79eab  role assistant   [toolCall]
credential_pin         id 6e83b720  parent 5d6c6f1d
custom                 id dc687348  parent 6e83b720  customType tool_execution_start
message                id 6d4f1ec5  parent dc687348  role toolResult  [text]
message                id 756d6d81  parent 6d4f1ec5  role assistant   [text]
custom                 id 8f0d1480  parent 756d6d81  customType session_exit
```

Every entry's `parent` is the previous `id` — a chain. `/tree` later turns the chain into a tree by pointing the leaf somewhere else.

Rename inside the TUI:

```text
> /rename M5 smoke session

 Session renamed to "M5 smoke session".

╭── π > ◒ Opus 5.5 > 🗑 m5lab > ⑂ master > S0.18 ▶─1%───────────╎┃─────1M─◀ M5 smoke session ──╮
╰─                                                                                          ─╯
```

The right end of the composer border is the `session_name` segment; `▶─1%` is `context_pct`.
