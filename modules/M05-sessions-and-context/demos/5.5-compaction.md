# Demo 5.5 — Compaction commands (≤ 45 s)

Captured on omp 18.3.1. The session was small (a 1M-token window at `▶─1%`), so the manual commands report their guard conditions — useful to recognise:

```text
> /compact Focus on what calc.py does and what was verified.

 Error: Compaction failed: Nothing to compact (session too small)

> /handoff focus on what remains to verify in calc.py

 Error: Handoff failed: Nothing to hand off (already compacted)

> /shake

 Nothing to shake.
```

What the same commands print once there is enough history (from omp://compaction.md and omp://handoff-generation-pipeline.md):

```text
> /handoff focus on the API refactor
 ⠋ Generating handoff… (esc to cancel)

 Context handed off and compacted in place

──────────────── 📷 compacted · ctrl+o ────────────────      ← divider at the point it fired
```

`Ctrl+O` on the divider expands the summary (or handoff document) including its `<files>` block:

```xml
<files>
# api/
__init__.py (Read)
server.py (RW)
## handlers/
orders.py (Write)
</files>
```

Where the number lives — the `context_pct` segment at the right end of the composer border:

```text
╭── π > ◒ Opus 5.5 > 🗑 m5lab > ⑂ master > S0.19 ▶─1%────────╎┃─────1M─◀ M5 smoke session ──╮
                                                  ^^^^ context %      ^^ window size
```

To make auto-compaction observable on a small repo, lower the trigger for the exercise:

```text
$ omp config set compaction.thresholdTokens 30000
✔ Set compaction.thresholdTokens = 30000
$ omp config get compaction.methodOrder
["remote","snapcompact","handoff","shake","soft"]
$ omp config reset compaction.thresholdTokens      # afterwards
```
