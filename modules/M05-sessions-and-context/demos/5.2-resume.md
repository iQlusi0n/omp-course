# Demo 5.2 — Resume three ways (≤ 60 s)

Captured on omp 18.3.1.

**`-c` from the same terminal** (the breadcrumb points at the session from demo 5.1):

```text
$ omp --session-dir /tmp/m5sessions -c -p "What file did we just look at? Answer with the filename only."
Working...
calc.py
```

**`--resume` by id prefix** (the id is `01a0d994-…`; the model sees the whole earlier conversation):

```text
$ omp --session-dir /tmp/m5sessions --resume 01a0d994 -p "How many user messages have I sent you so far in this conversation, including this one? Number only."
Working...
3
$ ls /tmp/m5sessions/
2026-09-25T17-19-21-278Z_01a0d994-2abe-763b-a400-292c817518fe.jsonl      ← still one file
```
