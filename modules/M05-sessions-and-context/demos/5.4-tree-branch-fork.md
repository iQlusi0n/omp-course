# Demo 5.4 — `/tree`, label, summarize, `/fork`, `/branch` (≤ 60 s)

Captured on omp 18.3.1 after three read-only turns.

**Open the tree** (`/tree`):

```text
╭─ Session Tree ────────────────────────────────────────────────────────────────────────╮
│                                                                                       │
│ Enter: switch. Alt+↑/↓: previous/next turn. PgUp/PgDn (←/→): page. Home/End: first/l… │
│ Search:                                                                               │
├───────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                       │
│   • user: Read calc.py and tell me in one sentence what the bug is. Do not edit anyt… │
│   • [read: calc.py]                                                                   │
│   • assistant: `add` in `calc.py` (line 2) returns `a - b` when it should return `a…  │
│   • user: In one sentence, what is the one-line fix? Do not edit anything.            │
│   • assistant: Change line 2 of `calc.py` from `return a - b` to `return a + b`.      │
│   • user: Which files are in this directory? Filenames only, no edits.                │
│   • [read: .]                                                                         │
│ › • assistant: calc.py notes/m5-session.html                                          │
╰───────────────────────────────────────────────────────────────────────────────────────╯
```

`•` marks the active path; `›` is the cursor (on the leaf). Pressing `Enter` here prints `Already at this point`.

**Label** — move the cursor, `Shift+L`, type `milestone`, `Enter`:

```text
│ › │  │  • [milestone] assistant: `calc.py` is already fixed, but not by me. My edit … │
```

On disk this is an append-only `label` entry: `{"type":"label","targetId":"675a9115","label":"milestone"}`.

**Tree after a few branches** (the same file; sibling branches hang off `├─` / `└─`):

```text
│   • assistant: calc.py notes/m5-session.html                                          │
│   ├─ • user: fix                                                                      │
│   │  • [edit: ]                                                                       │

│ › │  │  • [milestone] assistant: `calc.py` is already fixed, but not by me. …         │
│   │  └─ user: fix                                                                     │
│   │     assistant: `calc.py` is already fixed: line 2 now reads `return a + b` …      │
│   └─ user: fix                                                                        │
│      [edit: ]                                                                         │
│      assistant: I fixed line 2 of `calc.py`: it now returns `a + b` …                 │
```

**Summarize on switch** (`omp config set branchSummary.enabled true`, then `/tree`, type `one-line` in the search, `Enter`):

```text
╭─ Summarize branch? ───────────────────────────────────────────────────────────────────╮
│  ❯ No summary                                                                         │
│    Summarize                                                                          │
│    Summarize with custom prompt                                                       │
│ up/down navigate  enter select  esc cancel                                            │
╰───────────────────────────────────────────────────────────────────────────────────────╯
```

After `Summarize`:

```text
──────────────────────────── ⑂ branch · ctrl+o ────────────────────────────

 Navigated to selected point
```

The file gained `{"type":"branch_summary","parentId":"675a9115","fromId":"675a9115","summary":"…"}` at the new position.

Shell equivalent, `omp --fork 01a0d994 -p "Say FORKED."` → second file with `parentSession` and `providerPromptCacheKey` both equal to the source id.

**Branch** (`/branch`, default `doubleEscapeAction: rewind`) opens the transcript rewind selector:

```text
 18/18  ↑/↓ step  ←/→ user turns  enter rewind  ctrl+o expand  esc cancel
```

`←` to the previous user turn, `Enter`:

```text
──────────────────────────── ⑂ branch · ctrl+o ────────────────────────────

 Rewound to selected point

╭── π > … ──╮
╰─ Different direction: without editing anything, tell me in one line what add(2, 3) returns now. ─╯
```

The old prompt is back in the composer, ready to edit.
