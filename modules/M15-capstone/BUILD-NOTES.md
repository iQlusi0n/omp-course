## Deviations from the outline

- **Evidence item 6** — the outline says "`/review` verdict with P0–P3". `omp://slash-command-internals.md` documents `/review` only as the bundled review command that `/annotate code-review` submits to; no severity scale is documented. Reworded to "`/review` verdict + `/annotate` notes + `omp commit` producing ≥ 3 commits", and the README says explicitly that a P-scale must be requested in the review focus (as M13's `ci/review.sh` does). The rubric grades E6 on the review report referencing the notes and on ≥ 3 atomic `omp commit` runs.
- **"atomic commits"** — `omp commit --help` documents one generated commit per invocation (`--dry-run`, `--push`, `--no-changelog`, `--legacy`, `-c`, `-m`); there is no documented auto-split. The module teaches staging one slice and running `omp commit` per slice.
- **Evidence item 5 "seeded regression"** — interpreted as either the lab's DAP fixture `bin/crash.py` (Appendix A) or, preferably for a capstone, a real v2 question (breakpoint in `tools/migrate.py` on a v1 copy of the DB obtained with `git show module-15-start:data/lab.sqlite`). Both accepted by the rubric.
- **Evidence item 3 "Agent Hub screenshot"** — a terminal screenshot; there is no omp command that captures the Hub. Accepted as any image file plus the `Spawned N background agents` card.
- **`ci/review.sh` gate** — the M13 solution script (as of this build) exits 1 on `verdict: fail` as well as on P0. On the v2 diff the reviewer lists the seeded issues and votes `fail` (real run). The module therefore adds one scope sentence to the prompt and shows both runs; this is a genuine teaching point, not a workaround, and is flagged in the rubric (a learner who deletes the verdict check gets E9 = 1).
- **Managed skills path** — `~/.omp/agent/managed-skills/<name>/SKILL.md` per `omp://tools/learn.md`; `memory://root/learned.md` only under `memory.backend: local` (per the established corrections list).
- **Stretch items** (`/collab`, `WATCHDOG.md`, prewalk cost delta) are graded as bonus only; none was executed here (no second participant, no advisor model configured, prewalk needs an interactive session).
- **Lesson header duration** — Lesson 15.1 is the whole module (one lesson, five phases), so its header reads `(~180 min total; phases 15–60 min each)` instead of the template's `(~X min)`; the per-phase budgets are in `exercises.md`.
