# Module 15 cheat sheet — Capstone, by phase (omp/18.3.1)

Lab: `cd omp-course-lab && git checkout module-15-start && git switch -c v2` · spec `docs/V2-SPEC.md` · suite `python3 -m unittest discover -s tests` · seeded issues gate `LAB_ISSUE=all python3 -m unittest tests.test_issues` (16 failures, keep it that way).

## Phase 0 — inform (M6, M11)
| Do | Command / file |
|---|---|
| Project context | `.omp/AGENTS.md` (once per session) · `.omp/RULES.md` (every request) · `/extensions` to confirm |

## Phase 2 — implement (M2, M3, M4, M8)
| Do | Command / key |
|---|---|
| See before it runs | `omp --approval-mode write` · `bash.patterns: [{match: "python3 -m unittest*", approval: allow}]` in `.omp/config.yml` |
| Prompt shape | outcome · acceptance (`<cmd>` → expected) · scope ("not #1–#8") · verification · receipt (files + commands) |
| Read the result | error-marked `bash` card = failed; no `bash` card behind "tests pass" = unverified; `Ctrl+O` expand |
| LSP rename | `lsp {action: "rename", file, line, symbol, new_name}` → `Applied rename:` (`apply: false` previews) · `lsp references` first |
| Codemod | `ast_edit {ops: [{pat: "print($$$A)", out: "logger.info($$$A)"}], paths: ["cli"]}` → `Staged as a proposal…` → `write xd://resolve "<reason>"` → `Applied N replacements in M files.` (`xd://reject` discards) |
| Slice commit | `git add <slice files>` · `omp commit --dry-run` · `omp commit -c "v2 slice A: migration"` (`--no-changelog`, `-m <model>`) |
| Undo | `git restore .` / `git stash` · `/fork` for the conversation |
