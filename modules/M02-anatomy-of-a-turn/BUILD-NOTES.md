## Claims dropped or hedged as unverifiable

- **`/hotkeys` output layout** — not documented beyond "lists the active chords". Demo 2.1 tabulates the defaults from keybindings.md and says so; no claim about the on-screen layout or how to dismiss it.
- **`ask` picker key bindings** (Space to toggle a checkbox etc.) — ask.md documents the controls (`Other (type your own)`, `Done selecting`, ←/→ between questions) but not the toggle key. The lesson says "toggle the rows" without naming a key.
- **In-progress glyph in the todo card** — `omp gallery` only renders pending `☐`; the in-progress glyph/colour is not documented. Demo 2.5 annotates the row instead of inventing a glyph (`/todo` markdown uses `[/]`, which *is* documented).
- **Truncation warning wording on the bash card** — docs say the warning line "includes truncation reason and `artifact://<id>`"; the exact sentence in demo 2.2 is illustrative and labelled as a shape.
- **Model-facing elision marker text** for head+tail spills — documented as "an elision marker"; the demo's `[… KB / lines elided …]` line is illustrative.
- **Hashline stale-tag refusal wording** — edit.md lists the failure categories ("stale snapshot that cannot be recovered safely", "unknown snapshot tag", "outside the recorded seen-line ranges"); demo 2.3 uses those phrases and says the sentence is illustrative. The `omp gallery` failed-edit fixture shows a `replace`-mode message, not hashline, so it was not copied.
- **`omp ps` listing layout** — interactive monitor; not reproduced. Commands (`list|info|logs|stop|kill|restart`, `--plain`, `--json`) are from `omp ps --help`.
- **PTY exit code after `Esc`** — bash-tool-runtime.md says `Esc` kills the PTY and a PTY error finalizes with an undefined exit code; the `137` mapping is documented only for the client-terminal bridge. The demo card omits `Exit:`.
- **`@`-mention autocomplete details** — verified only that the TUI `@`-mention autocomplete uses cached `fuzzyFind` (fs-scan-cache-architecture.md) and that mentions become `fileMention` entries (session.md); no claim about the popup's layout or extra keys.
- **`generated/` tripping `edit.blockAutoGenerated`** — the guard reads the first 1024 bytes / 40 header lines for generated-file markers (write.md); the lab file has a `# GENERATED — do not edit` header, so this is expected but was not executed. Marked as expected behaviour in 2.3, not as observed.
- **`async.enabled` default** — not in settings.md's tables; verified `true` via `omp config list` (which prints effective values on this machine; the user config here does not set it). Stated as default with that provenance.
- **Composer default shape** — `omp gallery` labels `band` "(Default)"; this machine's user config sets `composer.shape: box`, which is why `omp config list` shows `box`. Module states `band` as the default per the gallery label.
