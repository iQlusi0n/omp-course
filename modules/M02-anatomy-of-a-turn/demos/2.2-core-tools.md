On disk: `~/.omp/agent/sessions/<encoded-cwd>/<timestamp>_<sessionId>/7.bash.log` (session-local id `7`, tool type `bash`).

Note the read card has plain line numbers and **no `#TAG`** — `artifact://` is immutable, so there is nothing to `edit`. A `grep 2999 artifact://7` would search the same file.
