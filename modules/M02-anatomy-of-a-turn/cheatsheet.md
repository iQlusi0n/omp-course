# Module 2 cheat sheet — Anatomy of a Turn (omp 18.3.1)

## Keys (defaults; action IDs remap in `~/.omp/agent/keybindings.yml`; `/hotkeys` shows live chords)

| Key | Action ID | Does |
|---|---|---|
| `Esc` | — | Interrupt the running turn (`interruptMode: immediate`); `Esc Esc` on empty editor → rewind picker (`doubleEscapeAction: rewind`) |
| `Ctrl+O` | `app.tools.expand` | Expand/collapse boxed tool cards |
| `Ctrl+Shift+O` | `app.tools.toggleVisibility` | Hide/show tool activity (`display.hideToolActivity`) |
| `Ctrl+T` | `app.thinking.toggle` | Show/hide thinking blocks (`hideThinkingBlock`, `--hide-thinking`) |
| `Shift+Tab` | `app.thinking.cycle` | Cycle thinking level (M3) |
| `Ctrl+R` | `app.history.search` | Search prompt history |
| `Ctrl+G` | `app.editor.external` | Edit draft in `$VISUAL`/`$EDITOR` |
| `Ctrl+Q`, `Ctrl+Enter` | `app.message.followUp` | Queue a follow-up (`followUpMode: one-at-a-time\|all`) |
| `Alt+Up`, `Shift+Up` | `app.message.dequeue` | Pull queued message back into the editor |
| `Ctrl+C` → `Up` | — | Clear draft, then recall it (`composer.recallClearedDrafts: true`); `Ctrl+C Ctrl+C` exits |
| `Ctrl+V` (`Alt+V` Win, `Cmd+V` mac) | `app.clipboard.pasteImage` | Paste image, text fallback; `Ctrl+Shift+V` raw text |
| `Alt+R` / `Alt+L` | `app.retry` / `app.display.reset` | Retry failed turn / redraw terminal |
| `Alt+Shift+L` / `Alt+Shift+C` | `app.clipboard.copyLine/copyPrompt` | Copy line / whole prompt |
| `!cmd` | — | Run a shell command locally, no model turn |
| `@path` | — | Attach file (fuzzy autocomplete); `omp @file "prompt"` on the CLI |

## Tool cards

| Tool | Card | Key args | Caps |
|---|---|---|---|
| `read` | boxed `• Read path[:sel]` | `path` + `:50` `:50-100` `:50+20` `:5-16,40-80` `:raw` `:conflicts` `:img` | 300 lines open-ended (`read.defaultLimit`); +1/+3 context on ranges; dir depth 2 × 12; summary for code ≥ 100 lines (`read.summarize.enabled`) |
| `grep` | inline `🔍 Grep: pat N matches · M files · in scope` | `pattern`, `path` (`a; b`, `file:50-100`), `case`, `gitignore`, `skip` | 20 files/page, 20/200 per file, ctx 1/3, 512-char lines, 30 s |
| `glob` | inline `🔍 Glob: pat N files · in base` | `path`, `hidden` (true), `gitignore` (true), `limit` (≤ 200) | mtime-desc; bare `*.py` → `**/*.py`; 5 s |
| `edit` | boxed `✎ Edit: file ⟦+a/-r⟧` + diff | `input` = `[PATH#TAG]` + hashline ops | existing files; tag from prior read/grep/edit/write |
| `write` | boxed `✎ Write: file · N lines` | `path`, `content` | creates/overwrites; refuses generated files (`edit.blockAutoGenerated`) |
| `bash` | boxed `$ cmd` / `Output` / `⟦Wall \| Timeout \| Exit⟧` | `command`, `timeout` (300; 0 = none; 1–3600), `cwd`, `pty`, `async`, `name`+`ready`+`env` | 50 KB spill → `artifact://N`; non-zero exit = failed card |
| `todo` | boxed `☑ Todo N tasks` + HUD | one op: `init start done drop block unblock rm append view` | one `in_progress`; tasks by exact content |
| `ask` | boxed `Ask N questions` → `✔ Ask` | `questions[{id, question, options[{label,description}], multi, recommended}]` | TUI only; `ask.timeout` (0), `ask.notify` (on); `Esc` cancels the turn |
| `web_search` | boxed `⌕ Web Search: Provider N sources` | `query`, `recency`, `limit` | provider from `modelRoles.web`; `providers.webSearchTimeoutSeconds` 60 |

## Truncation & artifacts

`tools.artifactSpillThreshold` 50 KB · head `tools.artifactHeadBytes` 20 KB · tail `tools.artifactTailBytes` 20 KB / `tools.artifactTailLines` 500 · line cap `tools.outputMaxColumns` 768
Model sees `Read artifact://<id> for full output` · file `<session-dir>/<id>.<tool>.log` · `read artifact://N[:1-200|:raw:1-3000]` · `grep re artifact://N` · > 8 MiB whole-read refused

## Hashline (`edit.mode: hashline`, default)

`[path#TAG]` + `LINE:TEXT` from `read`/`grep`/`edit`/`write` (not `:raw`, not `artifact://`/`skill://`/`agent://`) · ops `PUT N.=M:` `PUT <N:` `PUT >N:` `PUT >$:` `PUT N*:` `CUT N.=M` `REM` `MV` · numbers = original snapshot · stale tag → recovery or refuse → re-read · store 256 paths × 4 versions ≤ 4 MiB · `PI_EDIT_VARIANT` overrides

## `bash` runtime

Persistent shell per session (non-PTY, hardened env) · in-process coreutils incl. `jq` (jaq) · `scheme://` paths resolve in-shell · auto-background after `bash.autoBackground.thresholdMs` 60000 (`bash.autoBackground.enabled` on; `async.enabled` on) → `Backgrounded as job <id>` · `read proc://`, `read proc://<id>`, `write proc://<id>/kill`, `wait`
Services (`launch.enabled` on): `name` ≤ 48 + `ready:{port,log,host,timeout(30s)}` + `env`; not with `async`/`timeout` · `read proc://<name>` · `grep re proc://<name>` · `write proc://<name>` stdin · `…/kill` · `…/mode persist|session|detached` · `omp ps [list|info|logs|stop|kill|restart] <name>`
PTY: `pty: true`, TUI only, `PI_NO_PTY`/`--no-pty` off, `Esc` kills · Interceptor: `bashInterceptor.enabled` **off by default**, regex `patterns` → `Blocked: …` (cat→read, grep→grep, find→glob, sed -i→edit, echo >→write) · `bash.enabled: false` removes model tool, keeps `!`
