# Demo 10.5 — `@tool` + `agent()` + `workpool()` from the Python kernel (~60 s)

Each `▸ eval` block is one cell (one tool call). Cells share state. Helper signatures verified by `inspect.signature` on omp 18.3.5's Python prelude; JS shapes from the prelude source. Illustrative: the generated agent id, the exact keys inside `pool.status()` (the doc specifies "worker/item counts and context usage"), and the aggregate-result layout. The file list is the real `module-10-start` checkout (15 files).
