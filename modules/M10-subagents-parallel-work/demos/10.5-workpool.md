# Demo 10.5 — `@tool` + `agent()` + `workpool()` from the Python kernel (~60 s)

Each `▸ eval` block is one cell (one tool call). Cells share state. Helper signatures verified by `inspect.signature` on omp 18.3.1's Python prelude; JS shapes from the prelude source. Illustrative: the generated agent id, the exact keys inside `pool.status()` (the doc specifies "worker/item counts and context usage"), the `tests/` file names, and the aggregate-result layout.

