Swap the model without touching the file, then disable the agent:

```text
$ omp config set task.agentModelOverrides '{"test-writer":"@task"}'
$ omp config get task.agentModelOverrides
{"test-writer":"@task"}
   … dispatch again as TwApi2 → Alt+A row shows role @task (override beats frontmatter `model: "@smol"`)
$ omp config reset task.agentModelOverrides

$ omp config set task.disabledAgents '["test-writer"]'
   … dispatch → the tool returns a preflight error (no subagent runs) naming the disabled agent and listing the enabled alternatives (exact wording varies)
$ omp config reset task.disabledAgents
```

Precedence check — a project file shadows a bundled name (first-wins, exact case):

```text
$ cp /tmp/agents/scout.md .omp/agents/scout.md
$ sed -i 's/^description: "/description: "PROJECT OVERRIDE: /' .omp/agents/scout.md
❯ spawn a scout named Probe: list files in web/
❯ read history://Probe        → first system lines show "PROJECT OVERRIDE: …"
$ rm .omp/agents/scout.md     → next spawn uses the bundled scout again (discovery is re-run per spawn)
```
