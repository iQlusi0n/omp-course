Keep the artifacts, don't touch my tree:

```text
$ git checkout -- api cli
$ omp config set task.isolation.apply false
   … same spawn as IsoC / IsoD …
$ git status --short          (clean — nothing applied)
$ git apply "$(omp config path)/../sessions/…/artifacts/IsoC.patch"    # path from the inspector
$ omp config set task.isolation.apply true
```

Branch mode:

```text
$ omp config set task.isolation.merge branch
   … same spawn as IsoE / IsoF …
$ git log --oneline -3
a1b2c3d IsoF: append marker to cli/__init__.py      (cherry-picked from omp/task/IsoF)
d4e5f6a IsoE: append marker to api/__init__.py      (cherry-picked from omp/task/IsoE)
9f8e7d6 module-10-start
$ omp config set task.isolation.merge patch
```

Notes: the exact backend chosen by `auto` depends on the filesystem (Linux: kernel overlay → fuse-overlayfs → clone → rcopy). Commit messages in the branch-mode example are illustrative (`task.isolation.commits: generic` by default).
