Equivalents from the composer (what the *model* uses to supervise its own children):

```text
❯ read proc://                → jobs + services, no delivery consumed
❯ read proc://Slowpoke        → status/output tail
❯ write proc://Doomed/kill    → same as Hub `x`
❯ read history://             → lists registered agents (running, idle, parked)
❯ wait                        → (tool, no args) blocks until the next settled job / peer message; "Nothing to wait for" when none
```
