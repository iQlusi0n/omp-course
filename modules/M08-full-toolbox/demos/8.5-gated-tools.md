# Demo 8.5 — flipping a gate (~40 s)

The `omp config` lines were captured on `omp/18.3.1`. The build machine has no `gh`, image model, speech model or IDA, so the card bodies below are the result shapes documented in `omp://tools/*.md`, not live captures — the exact wording your run prints is decided by the tool; the *structure* is what to look for.

## Defaults (all five in one glance)

```
$ omp config get github.enabled;        # false
$ omp config get security.enabled;      # false
$ omp config get generate_image.enabled # false
$ omp config get speechgen.enabled      # false
$ omp config get ida.enabled            # true   (tool still absent without an IDA install)
$ omp config get debug.enabled          # true
$ omp config get astGrep.enabled        # false
$ omp config get astEdit.enabled        # true
$ omp config get find.enabled           # auto
$ omp config get tools.xdev             # true
```

$ omp config set github.enabled true
$ omp config get github.enabled
