# Demo 8.2 — `eval` keeps state and can call tools (~45 s)

Captured on `omp/18.3.1` (`omp -p --mode json`, tool cards flattened). Three `eval` calls, one cell each. Notice cell 2 has no reload and cell 3 calls `tool.read` from *inside* the kernel.

```
> Using eval (py): count orders per month from data/lab.sqlite into by_month and display it.
  Then, in a second cell, display(sum(by_month.values())) without reloading.
  Then display(await tool.read({'path': 'data/lab.sqlite'})).

╭─ eval py · Counting orders per month ────────────────────────────────────╮
│ import sqlite3                                                           │
│ con = sqlite3.connect('data/lab.sqlite')                                 │
│ rows = con.execute('select created_at from orders').fetchall()           │
│ by_month = {}                                                            │
│ for (c,) in rows:                                                        │
│     k = c[:7]                                                            │
│     by_month[k] = by_month.get(k, 0) + 1                                 │
│ display(by_month)                                                        │
├──────────────────────────────────────────────────────────────────────────┤
│ {'2026-01': 10, '2026-02': 10, '2026-03': 10, '2026-04': 10,             │
│  '2026-05': 10, '2026-06': 10}                                           │
│                                                                          │
│ display[1]:                                                              │
│ {                                                                        │
│   "2026-01": 10,                                                         │
│   "2026-02": 10,                                                         │
│   "2026-03": 10,                                                         │
│   "2026-04": 10,                                                         │
│   "2026-05": 10,                                                         │
│   "2026-06": 10                                                          │
│ }                                                                        │
╰──────────────────────────────────────────────────────────────────────────╯

╭─ eval py · Summing monthly counts ───────────────────────────────────────╮
│ display(sum(by_month.values()))                                          │
├──────────────────────────────────────────────────────────────────────────┤
│ 60                                                                       │
╰──────────────────────────────────────────────────────────────────────────╯

╭─ eval py · Reading DB via tool bridge ───────────────────────────────────╮
│ display(await tool.read({'path':'data/lab.sqlite'}))                     │
├──────────────────────────────────────────────────────────────────────────┤
│ {'text': 'orders (60 rows)\nusers (10 rows)', 'details': {'resolvedPath':│
│ '/…/data/lab.sqlite', 'meta': {'source': {'type': 'path', 'value':       │
│ '/…/data/lab.sqlite'}}}}                                                 │
│                                                                          │
│ display[1]:                                                              │
│ {                                                                        │
│   "text": "orders (60 rows)\nusers (10 rows)",                           │
│   "details": { "resolvedPath": "/…/data/lab.sqlite", … }                 │
│ }                                                                        │
╰──────────────────────────────────────────────────────────────────────────╯

I ran all three cells, and nothing was written to disk.
1. Orders per month: each month from 2026-01 through 2026-06 has 10 orders.
2. Total: 60. This cell reused `by_month` from cell 1 without reloading the data.
3. Tool bridge: `tool.read` worked … two tables: orders (60 rows) and users (10 rows).
```

What to notice:

- `display()` output appears twice: once as plain text and once under `display[1]:` as a JSON tree (that structured value is what the model sees, capped at 8000 chars).
- `tool.read` is `await`ed — it is a coroutine in Python. The return value is the tool's result object (`text` + `details`), not a bare string.
- No `bash` cards, no temp files, no `python -c`.
