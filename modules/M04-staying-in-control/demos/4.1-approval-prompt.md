# Demo 4.1 — Approval modes (≤ 60 s)

Shell lines are a real transcript captured on omp 18.3.1 in a scratch profile (`OMP_PROFILE=m04-build`). The in-session part is illustrative: the exact rendering of the approval card is not documented beyond its body lines (`Allow tool: <name>`, optional `Origin:`/`Reason:`, tool details).

```text
$ omp --version
omp/18.3.1
$ omp config get tools.approvalMode
yolo                                   ← the default: nothing prompts
$ omp config set tools.approval '{"bash":"prompt"}'
✔ Set tools.approval = {"bash":"prompt"}
$ omp config get tools.approval
{"bash":"prompt"}
$ omp config reset tools.approval
✔ Reset tools.approval to {}
```

```text
$ omp --approval-mode always-ask
> Fix issue #4 (add the stats subcommand). Run python3 -m unittest discover -s tests before and after.

▸ read  docs/ISSUES.md                     (tier read → auto-approved even in always-ask)
▸ read  cli/__main__.py
▸ grep  "add_parser" cli/

┌ Approval ─────────────────────────────────────────────┐
│ Allow tool: bash                                      │
│ command: python3 -m unittest discover -s tests        │
│ cwd: /home/you/omp-course-lab                         │
│ [Allow]   [Deny]                                      │
└───────────────────────────────────────────────────────┘
  → Allow

▸ bash  python3 -m unittest discover -s tests   …  OK (11 tests)

┌ Approval ─────────────────────────────────────────────┐
│ Allow tool: edit                                      │
│ path: cli/commands.py                                 │
│ [Allow]   [Deny]                                      │
└───────────────────────────────────────────────────────┘
  → Deny

  The edit to cli/commands.py was not approved. Do you want the stats command
  in a separate module instead, or should I retry the same edit?
> Retry the same edit.
  → Allow …
```

Point to make: `read` never asked; `bash` (exec) and `edit` (write) both asked because the mode was `always-ask`. The same run under the default `yolo` would show no cards at all.
