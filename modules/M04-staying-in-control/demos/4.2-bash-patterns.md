# Demo 4.2 — `bash.patterns` (≤ 60 s)

Shell part is a real transcript captured on omp 18.3.1 in a scratch profile (`OMP_PROFILE=m04-build`). The session part is illustrative.

```text
$ omp config get bash.patterns
[]
$ omp config set bash.patterns '[{"match":"python3 -m unittest*","approval":"allow"},{"match":"rm -rf *","approval":"deny"}]'
✔ Set bash.patterns = [{"match":"python3 -m unittest*","approval":"allow"},{"match":"rm -rf *","approval":"deny"}]
$ omp config get bash.patterns --json
{
  "key": "bash.patterns",
  "value": [
    { "match": "python3 -m unittest*", "approval": "allow" },
    { "match": "rm -rf *", "approval": "deny" }
  ],
  "type": "array",
  "description": "Ordered bash command approval rules. Each item has match and approval fields; only '*' wildcards are supported."
}
$ omp config get bash.allowCompoundCommands
false
$ omp config set tools.approvalMode write
✔ Set tools.approvalMode = write
```

```text
$ omp
> Run the test suite and report counts.

▸ bash  python3 -m unittest discover -s tests            (no approval card: rule 1 → write tier, auto-approved)
  ...
  Ran 12 tests in 0.31s
  OK

> Delete .pytest_cache with rm -rf.

▸ bash  rm -rf .pytest_cache                              ✗ denied by bash.patterns rule "rm -rf *"
  The command was denied by policy. I won't remove the directory; you can delete it manually.

> Run the tests then remove .pytest_cache in one && command.

▸ bash  python3 -m unittest discover -s tests && rm -rf .pytest_cache
                                                          ✗ denied: segment "rm -rf .pytest_cache" matches deny rule
```

Point to make: `allow` lowered the simple test command to the `write` tier; `deny` is checked per segment, so the chain is refused even though its first half is allowed — and it would be refused under `--yolo` too.

```text
$ omp config reset bash.patterns
✔ Reset bash.patterns to []
```
