# Demo 4.3 — Plan mode and the Plan Review overlay (≤ 60 s)

Illustrative transcript (no model on the build machine). Keys and flow verified against omp://keybindings.md, omp://slash-command-internals.md §13, omp://resolve-tool-runtime.md, omp://session-tree-plan.md.

```text
$ omp
[Alt+Shift+P]                                   ← app.plan.toggle
  plan mode: on

> Implement issue #5 (order cancellation). Propose a plan with one section per sub-item.

▸ read  docs/ISSUES.md
▸ grep  "def do_(GET|POST)" api/server.py
▸ read  api/server.py:40-120
▸ read  cli/__main__.py
▸ glob  tests/*.py
▸ write local://order-cancellation-plan.md        (plan text lives at local://<slug>-plan.md, not in the repo)
▸ write xd://propose   "order-cancellation"       (submits the plan → Plan Review overlay)

┌ Plan Review: order-cancellation ─────────────────────────────────────────┐
│ Contents                    │ ## 1. DELETE /orders/<id> in api/server.py │
│ ▸ 1. DELETE /orders/<id>    │ - add route, 404 on unknown id             │
│   2. cli cancel <id>        │ - mark status=cancelled in data/lab.sqlite │
│   3. Email the customer     │ ## 2. `python3 -m cli cancel <id>`         │
│                             │ …                                          │
│ a annotate  e edit  u undo  │ ## 3. Email the customer                   │
└─────────────────────────────┴────────────────────────────────────────────┘
  [↓ ↓ to "3. Email the customer"]  [a]
  ┌ Note ───────────────────────────────────────┐
  │ Out of scope for this issue — do not implement│  Enter
  └─────────────────────────────────────────────┘
  [Escape]                                       ← leave overlay, still in plan mode
> /plan-review                                   ← overlay reopens, note intact
  [Approve]                                       (choice: fresh / preserved / compacted context)

  plan mode: off · session named "Order cancellation"
▸ edit  api/server.py
▸ edit  cli/__main__.py
▸ write tests/test_cancel.py
▸ bash  python3 -m unittest discover -s tests   … OK
```
