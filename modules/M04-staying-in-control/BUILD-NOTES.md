## Deviations from COURSE-OUTLINE.md
- **Outline 4.5: "`omp commit` (atomic split, dependency-ordered, lock files excluded)"** — not found in any `omp://` doc or in `omp commit --help`. Dropped. The lesson teaches the documented flags, the model requirement, and the observed staging behavior. The related documented fact `edit.blockAutoGenerated: true` (refuses generated/lockfile-like edits) is taught instead.
- **Outline 4.4: "`/review` (reviewer subagents, P0–P3 verdict)"** — `/review` is only documented indirectly (slash-command-internals.md §12: the annotate overlay "submits the `/review` prompt"; exclusion rules in `bundled/review/diff.ts`). No doc describes a P0–P3 verdict scale. The lesson teaches `/review` as the bundled review prompt and names the bundled `reviewer`/`security-reviewer` agents (tools/task.md); the P0–P3 claim is dropped. Capstone criterion 6 ("`/review` verdict with P0–P3") should be re-checked by M15's builder.
- **Outline W coursework: `bash.patterns` allow rule for `npm test`** — lab is Python-only; rule targets `python3 -m unittest*` (LabRepo-confirmed test command `python3 -m unittest discover -s tests`).
- **Outline 4.3: "Plan Review overlay (`/plan-review`, `a`/`e`/`u` annotate sections); accept → implement"** — verified. The approval choice set (fresh / preserved / compacted context, "Approve and compact context") comes from session-tree-plan.md + compaction.md; exact button labels are not documented, so the lesson describes them generically.
- **Approval prompt keys** — approval-mode.md documents the card's body lines (`Allow tool:`, `Origin:`, `Reason:`, details) but not the accept/deny keys. Demo 4.1 draws `[Allow] [Deny]` as illustrative; the lesson says "choose the allow or deny option".
- Outline lists README as a source for `/review`, `omp commit`, `conflict://`; the bundled `omp://` index has no README. Sources cited are the doc files above plus `--help` output.
