# Module 4 cheat sheet — Approvals, Plan Mode, Review, Commit (omp 18.3.1)

## Approval modes (4.1)
| Mode | Auto-approves | Prompts |
|---|---|---|
| `always-ask` | `read` | `write`, `exec` |
| `write` | `read`, `write` | `exec` |
| `yolo` **(default)** | all | none |

| Do | Command / key |
|---|---|
| See mode | `omp config get tools.approvalMode` |
| Set persistently | `omp config set tools.approvalMode write` (writes `~/.omp/agent/config.yml`) |
| One session | `omp --approval-mode always-ask\|write\|yolo`; `--auto-approve` / `--yolo` = yolo |
| Per-tool override | `omp config set tools.approval '{"bash":"prompt","edit":"allow"}'` (`allow\|deny\|prompt`, any mode) |
| Reset | `omp config reset tools.approval` |
| Tiers | `read` < `write` < `exec`; undeclared tools = `exec`; MCP tools = `write` |
| Prompt card | `Allow tool: <name>` · `Reason: …` · command/path details |
| Subagents | run `yolo`; `tools.approval.<tool>` still applies (`prompt` → rejected headless) |

## Bash patterns (4.2)
| Do | Command / setting |
|---|---|
| Rules | `bash.patterns: [{match: "git *", approval: allow}, …]` — first match wins, `*` only wildcard |
| Set / get / reset | `omp config set bash.patterns '[{"match":"python3 -m unittest*","approval":"allow"}]'` · `omp config get bash.patterns --json` · `omp config reset bash.patterns` |
| Semantics | `deny` absolute (even yolo) · `prompt` forces prompt · `allow` → `write` tier for a *simple* command |
| Compound `&&` chains | `bash.allowCompoundCommands: true` (default false); all segments must `allow`; deny > prompt > allow |
| Not a sandbox | approved command keeps FS/network; `eval` bypasses → add `tools.approval.eval: prompt` |
| Not routing | `bashInterceptor.patterns` decides *which tool*, not *whether* |

## Plan mode (4.3)
| Do | Key / command |
|---|---|
| Toggle | `Alt+Shift+P` (`app.plan.toggle`, remap in `~/.omp/agent/keybindings.yml`) |
| Settings | `plan.enabled: true` · `plan.defaultOnStartup: false` |
| Reopen review | `/plan-review` (plan mode only) |
| Overlay | `a` annotate section/line · `e` edit · `u` undo · `Enter` save · `Shift+Enter` newline · `Escape` discard |
| Headless | `omp --plan-yolo [--plan-yolo-into <model>]` (default target: `smol` role) |
| Plan model | `--plan <id>` · `PI_PLAN_MODEL` · `modelRoles.plan` |
| While active | writes refused; subagents read-only (`read`,`grep`,`glob`,`web_search`); `ask` never times out |

## Review & annotate (4.4)
| Do | Command |
|---|---|
| Diff notes | `/annotate code-review [focus]` (menu: PRs mentioned, then local diff kinds) |
| Skip menu | `/annotate code-review pr://owner/repo/N [focus]` |
| Other sources | `/annotate last` · `/annotate session` · `/annotate path` · `/annotate "text"` · `/annotate ./code-review` (file literally so named) |
| Keys | `a` line · `A` whole file/text · `e` edit · `u` undo · `Enter`/`Shift+Enter`/`Escape` |
| Exits | **Continue with LLM review** (submits `/review` with notes as focus) · **Paste annotations into prompt** |
| Text-source result | pasted into composer, never auto-sent |
| PR preview | `read pr://N` · `pr://owner/repo/N` · `pr://N/diff` · `?comments=0` · bare `pr://?state=open&limit=5` (needs `gh`) |

## Commit & conflicts (4.5)
| Do | Command |
|---|---|
| Commit | `omp commit [--dry-run] [--push] [--no-changelog] [--legacy] [-c "context"] [-m model]` |
| Needs model | else `No model available for commit generation`; roles tried: `commit`, then `smol` |
| Scope | staged files → commits only those; nothing staged → stages everything. Does **not** conclude an in-progress merge (use `git commit`) |
| Git UI | `omp git [REVISION] [-C dir]` |
| Find conflicts | `read <file>:conflicts` → `⚠ N unresolved conflict… #1 L2-6` |
| Inspect | `read conflict://1` · `conflict://1/ours` · `/theirs` · `/base` · `/both` |
| Resolve one | `write conflict://1` content: `@ours` \| `@theirs` \| `@base` \| `@both` \| literal lines |
| Resolve all | `write conflict://*` same content, or `1: @ours⏎2: @theirs` |
| Stale id | re-run `read <file>:conflicts` (ids are session-scoped, invalidated on resolve) |
| Generated files | `edit.blockAutoGenerated: true` (default) refuses generated/lockfile-like edits |

## Undo (4.6)
| Do | Command |
|---|---|
| Files | `git restore .` · `git stash` · branch first; tell omp to re-read after a revert |
| Conversation | `/fork` (persistent session, not while streaming) · `omp --fork <id\|path>` |
| Later | `/tree` `/branch` `/resume` (M5) · `checkpoint`/`rewind` tools (M9/M11, off by default) |
