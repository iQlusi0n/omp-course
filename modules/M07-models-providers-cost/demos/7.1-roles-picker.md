Captured on `omp/18.3.1` in an isolated profile whose only credentials-free providers are the lab mock (`mock`, `mock-backup`), the `local` tiny catalog and the keyless `web` search providers. On your machine the `●` rows are your logged-in providers.

What to notice:
- Left column: `✦ Roles` (1 of 15 roles assigned), `⬢ All models`, then providers. `●` = available (keyless or credentialed), `○` = present in the catalog but not selectable.
- Right column: the merged model list with a **Kind** filter (`Alt+←/→`), price per million (`free` here), measured tokens/s and TTFT, and the selected model's role dots (`● default ◒ · ○ smol · ○ slow …`).
- Bottom bar after pressing Enter on a row: `mock-1 → [ ● default ✔ ]  smol   slow   vision   plan   commit   tiny   memory   task   advisor   judge   fallbacks…` — move along it and press Enter to assign. Only `default` also switches the live model.
- The footer when nothing is selected: `Enter assign roles · ↑/↓ providers · → models · type to search · Alt+←/→ kind · Esc close`.

After assigning from a shell:

```
$ omp config set modelRoles '{"default":"mock/mock-1","smol":"mock-backup/mock-1","slow":"mock/mock-1:high"}'
✔ Set modelRoles = {"default":"mock/mock-1","smol":"mock-backup/mock-1","slow":"mock/mock-1:high"}
$ omp config get modelRoles
{"default":"mock/mock-1","smol":"mock-backup/mock-1","slow":"mock/mock-1:high"}
$ sed -n '/^modelRoles:/,/^[a-z]/p' "$(omp config path)/config.yml"
modelRoles:
  default: mock/mock-1
  smol: mock-backup/mock-1
  slow: mock/mock-1:high
```

Startup warning you will see if a chain or role points at a model omp cannot find:

```
 Warning: Fallback chain for role 'default' references unknown model: nosuch/model-9
```
