# Demo 7.6 — `omp stats --summary`, the dashboard, `--json`          (~30 s)

Captured on `omp/18.3.1` after one mock-backed turn (the mock is priced at `0`, so `Total Cost` is `$0.0000` — an *unpriced* model, not a free real one).

```
$ omp stats
Syncing session files...
Synced 5 new entries from 1 files (5 total)

Dashboard available at: http://127.0.0.1:3847
Press Ctrl+C to stop
```

```
$ omp stats --json | sed -n '/^{/,$p' | python3 -c 'import json,sys; d=json.load(sys.stdin); print(list(d)); print(list(d["overall"]))'
['overall', 'byModel', 'byFolder', 'byAgentType', 'timeSeries', 'modelSeries', 'modelPerformanceSeries', 'costSeries']
['totalRequests', 'successfulRequests', 'failedRequests', 'errorRate', 'totalInputTokens', 'totalOutputTokens', 'totalCacheReadTokens', 'totalCacheWriteTokens', 'cacheRate', 'cacheSavings', 'totalCost', 'unpricedRequests', 'totalPremiumRequests', 'avgDuration', 'avgTtft', 'avgTokensPerSecond', 'firstTimestamp', 'lastTimestamp']
```

Note the `Synced …` line printed **before** the JSON object — pipe through `sed -n '/^{/,$p'` before parsing. `overall.unpricedRequests` is the counter that tells you how much of `totalCost` is missing because models had no pricing.

Aggregates live in `~/.omp/stats.db` (created on first run) and come from `~/.omp/agent/sessions/`.
