# Demo 7.3 — `omp usage`, `.env` precedence, path-scoped `disabledProviders`          (~60 s)

Captured on `omp/18.3.1`, isolated profile (no stored accounts). The mock from 7.4 is listening on port 8775 in this capture (8765 in the lab).

## A repo-local `.env` drives discovery — and the process env beats it

`lab/.env` contains `LM_STUDIO_BASE_URL=http://127.0.0.1:8775/v1`. The discovery cache (`<agent dir>/models.db`) was removed between runs so each result is a fresh probe.

```
$ cd ~ && omp models lm-studio                      # 1) no .env here → default :1234 → nothing
No models matching "lm-studio"

$ cd lab && LM_STUDIO_BASE_URL=http://127.0.0.1:1 omp models lm-studio   # 2) exported var wins over .env
No models matching "lm-studio"

$ cd lab && omp models lm-studio                    # 3) .env read because cwd is the repo
lm-studio (1)
┌────────┬─────────┬─────────┬──────────┬────────┐
│ model  │ context │ max-out │ thinking │ images │
├────────┼─────────┼─────────┼──────────┼────────┤
│ mock-1 │    128K │     33K │ -        │ no     │
└────────┴─────────┴─────────┴──────────┴────────┘
```

Mock stderr during step 3 — omp's LM Studio discovery tries a native route first, then the OpenAI list:

```
[mock-provider] GET /api/v0/models -> "GET /api/v0/models HTTP/1.1" 404 -
[mock-provider] GET /v1/models -> "GET /v1/models HTTP/1.1" 200 -
```

Caveat seen in the capture: once discovered, the row stays in `models.db` and still prints from `~` until the cache is refreshed or deleted.

## Path-scoped `disabledProviders` / `enabledModels`

Global `config.yml`:

```yaml
enabledModels:
  - path: /tmp/m07-smoke/proj
    models:
      - mock-backup/mock-1
disabledProviders:
  - path: /tmp/m07-smoke/private
    providers:
      - mock
```

```
$ cd /tmp/m07-smoke/elsewhere && omp models | grep -E '^\S.*\('
mock (1)
mock-backup (1)
$ cd /tmp/m07-smoke/private && omp models | grep -E '^\S.*\('
mock-backup (1)                                   # `mock` removed only here
$ cd /tmp/m07-smoke/proj && omp config get enabledModels
["mock-backup/mock-1"]
$ cd /tmp/m07-smoke/elsewhere && omp config get enabledModels
[]
$ cd /tmp/m07-smoke/private && omp config get disabledProviders
["mock"]
```

`omp config get` prints the value **resolved for the current directory**, which is the fastest way to debug "why is this provider missing here".
