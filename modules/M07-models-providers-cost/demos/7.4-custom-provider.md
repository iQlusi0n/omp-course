# Demo 7.4 — Custom provider from `models.yml`, a broken file, discovery, `omp commit`          (~60 s)

Captured on `omp/18.3.1`, isolated profile. Port 8765 is the lab default; the capture used 8775 in one run — treat the number as "the port you started the mock on".

## Start the mock and declare it

```
$ python3 tools/mock-provider.py --port 8765
mock-provider serving model 'mock-1' on http://127.0.0.1:8765/v1 in normal mode
```

`~/.omp/agent/models.yml`:

```yaml
providers:
  mock:
    baseUrl: http://127.0.0.1:8765/v1
    api: openai-completions
    auth: none
    models:
      - id: mock-1
        name: Mock 1 (omp-course-lab)
        reasoning: false
        input: [text]
        contextWindow: 32768
        maxTokens: 4096
        cost:
          input: 0
          output: 0
          cacheRead: 0
          cacheWrite: 0
```

```
$ omp models mock
mock (1)
┌────────┬─────────┬─────────┬──────────┬────────┐
│ model  │ context │ max-out │ thinking │ images │
├────────┼─────────┼─────────┼──────────┼────────┤
│ mock-1 │     33K │    4.1K │ -        │ no     │
└────────┴─────────┴─────────┴──────────┴────────┘

$ omp -p --model mock/mock-1 --no-session "say hi"
Working...
Hello from mock-1. You said: say hi
```

(The mock strips omp's injected `<system-reminder>` block before echoing the first 80 characters of the user message, so `say hi` comes back verbatim.) Mock stderr: `[mock-provider] POST /v1/chat/completions -> "POST /v1/chat/completions HTTP/1.1" 200 -`.

## What a broken file looks like

`baseUrl` removed:

```
$ omp models
Warning: models.yml validation failed — custom providers disabled
  Failed to load config file models, Validate(models) error: Provider broken: "baseUrl" is required when defining custom models.

No models available. Set API keys in environment variables.
```

(The last line appears only because this profile has no other provider; on your machine the built-in tables still print.)

## `omp commit` resolves the `commit` role

`config.yml`: `modelRoles: {default: mock/mock-1, commit: mock-backup/mock-1}`; one staged change.

```
$ omp commit --dry-run
● Resolving model...
  └─ Mock 1 (backup)
● Detecting changelog targets...
  └─ (none found)
● Discovering context files...
  └─ (none found)
● Starting commit agent...
● Hello from mock-1. You said: …
● agent finished (1 messages, 0 tools)
…
● Agent did not provide proposal, using fallback...
Warnings:
- Commit generated using fallback due to agent failure

Generated commit message:
docs: updated documentation for a.txt

- Updated a.txt
```

The first card proves role resolution; the fallback message is expected for a canned mock (a real Ollama model produces a proposal).
