# Tool inventory — default-on vs setting-gated

Defaults from `omp read cfg://<key>` (definition defaults). "Essential" tools are always in the model's top-level list; "discoverable" tools may instead be presented as `xd://<tool>` devices when `tools.xdev: true` (default) — same tool, dispatched via `write xd://<tool>` with a JSON body. `omp --tools a,b,c` pins the list for one run; `--no-tools` removes model tools. Approval tiers: `read` < `write` < `exec` (see M4).

## Bash interceptor (`bashInterceptor.enabled` ⚠ false)

Default `bashInterceptor.patterns` map `cat/head/tail` → `read`, `grep/rg` → `grep`, `find/fd` → `glob`, `sed -i`/`perl -i` → `edit`; a match returns `Blocked: …` and the model must use the tool. It routes *which tool*, never *whether* (that is `bash.patterns` / `tools.approval`).
